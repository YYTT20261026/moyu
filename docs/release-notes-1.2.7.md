# 摸鱼 v1.2.7

> 本次先发布 macOS 版本；Windows / Android / Web 仍为 v1.2.6，可继续使用此前的 Release 附件。

## 修复
- **四季花树前景遮挡**：右上角伸出的花枝现在正确盖在锦鲤前面——按季节从底图提取花瓣、叶片与枝条作为前景遮罩，枝叶间的水面仍然透得出来，鱼的游动范围不变。此前从花树下穿过的鱼看起来像浮在叶子上面。
- **Canvas 后备路径对齐**：没有 WebGL 时（部分老 Mac、手机竖屏），前景遮罩、锦鲤和 CSS 底图现在共用同一套旋转裁切矩阵，花枝不再和鱼错位。底图不允许像素回读时自动保留岸线遮罩，换季不会中断。
- **锦鲤触岸迟钝／卡顿**：靠近岸线时锁定一个绕行方向，沿切向内弧快速转身，不再对着岸边来回摆头；碰撞只抵消朝岸的分量、保留沿岸滑行的速度，减速改为按时间衰减，不再每帧固定砍掉一半。
- **快速转头不再拉直鱼身**：原先按鼻尖位移判断鱼身是否需要重置，急转弯时会误判成瞬移；现在只看鱼身中心的实际位移。加速播放和低帧率下把游动拆成最多 1/30 秒的小步，转弯弧线连续，食物寿命与生长仍按真实时间计算。

## 验证
- 完整测试 93 项全部通过。新增前景提取、图层顺序、横竖屏与双屏、回读降级、触岸滑行、帧率一致性、脊柱连续性等回归用例。
- 四季 390×844 竖屏、24 尾鱼、15 秒追食／受惊对照中，优化后不再出现静止帧。
