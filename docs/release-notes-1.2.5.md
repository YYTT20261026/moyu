# 摸鱼 v1.2.5

## 新增
- **跟随城市天气自动昼夜**：勾选「跟随城市天气」并选好城市后，从天气接口同步当地日出/日落，以事件为中心用 40 分钟连续混合白天与夜晚的光照、天空、水色与月亮倒影，而不是突然切换。日出/日落时刻才会覆盖「月下观鱼」的开关，手动设置保持到下一次日出日落。
- **一键还原体型**：在「我的锦鲤」单尾小传里点「还原体型」回到入池体型；列表顶部「全部还原体型」一键还原所有锦鲤与青鲢（青鲢还原为原体的六成）。累计食量、排行榜、陪伴天数全部保留，之后吃食会重新长大；存档与跨窗口同步。
- 面板内新增独立的操作提示，Windows「我的锦鲤」面板里也能看到还原反馈。

## 调整
- 受惊游开速度调慢约 30%（点水、右键、拖手惊鱼都更从容），转身仍保持灵活。
- 锦鲤尺寸上限统一为 96px；乌龟整体缩小 0.8。
- 「我的锦鲤 / 天气 / 池塘设置」右上角关闭按钮恢复。

## 修复
- 修复鱼在岸边鱼食处顶着岸反复抖动的卡顿。

## 下载（Release 附件，ASCII 命名）
- Windows：`MoYu-1.2.5-Windows.exe`（安装器） / `MoYu-1.2.5-Windows.zip`（便携版）
- macOS：`MoYu-1.2.5-macOS.dmg`（需在 Mac 上构建，本版本未附）
- Android：`MoYu-1.2.5-Android.apk`
- Web：`MoYu-1.2.5-Web.zip`

> Android APK 使用本机新签名密钥，无法直接覆盖旧版安装（需先卸载旧版）。
> 安装器未签名，Windows 首次运行会有 SmartScreen 提示。
