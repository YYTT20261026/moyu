# MoYu v1.2.8

> 本次统一更名为 **MoYu**，并把 Windows / Android / Web 全部更新到 1.2.8。macOS 版需要在 Mac 上构建；附件暂未包含，构建完成后补传。

## 更名与升级

- 程序名、安装目录、快捷方式、卸载项、窗口/托盘/菜单文案统一为 **MoYu**（原「摸鱼」）。
- 安装器会自动迁移旧版：删除旧目录、旧快捷方式与旧卸载项；若曾开启「开机时启动」，保留选择并把路径改指新安装位置，不会出现两份池塘。

## 新功能

- **屏幕显示**（设置）：单屏幕显示 / 多屏幕显示 / 多屏共用显示，默认单屏幕。
  - Windows 共用模式用一个窗口覆盖整个虚拟桌面，macOS 用所有屏幕的并集；画面连续，鱼可以游过屏幕边界。
  - 选择写入 `%LOCALAPPDATA%\BichiPond\screen-mode.txt`（macOS 为 UserDefaults），重启后保持。
- **月下观鱼**：月亮倒影会随时间横穿池塘。
  - 跟随城市时按真实日落 → 日出移动；手动开启或没有日出日落数据时，以 24 分钟为一轮缓慢往返。
  - 水面月光、碎光与「点月亮放河灯」的判定位置一起移动。

## 性能与资源

- 面板只加载界面与鱼预览，**不再创建池塘 WebGL / 四季纹理**；预览只在面板打开时绘制。
- Windows 壁纸只保留当季底图纹理，CPU 底图缓存设 64MB 预算；换季按需重新加载/上传。
- 页面就绪、重载后可靠补发暂停状态；桌面被遮挡或锁屏时停止无效绘制。
- 名字/聊天画布按需分配（关闭时缩到 1×1）；复用精确水域距离、天气对象与临时数组；完整释放 WebGL 资源、合并窗口 resize、修正帧率上限。
- 实测（Windows 单屏 2048×1152）：GPU 专用显存 **779 MB → 256 MB**，私有内存 **约 1.12 GB → 约 548 MB**；暂停时 CPU **2.6% → 1.0%**（单核）。

## 修复

- **Wallpaper Engine 随系统启动且页面初始隐藏时只显示静图**：现在同步绘制首帧，隐藏不再阻止第一帧；恢复可见后继续动画。
- **Windows**：32 位系统 `GetWindowLong` 崩溃；某块屏幕 WebView2 失败导致无限重建；面板已释放时 `Close()` 崩溃；四季缩略图在安装包里缺失。
- **macOS**：Finder 窗口、交互窗口等任何窗口上方的点击不再投喂，只有真正裸露的桌面才算轻点；交互窗口最小化后桌面轻点恢复。
- **安装器**：版本号改为读取程序集；安装/卸载前结束运行中的旧进程；卸载先删目录再删注册表，失败可重试；删除前校验目录确实是安装目录，避免误删。
- **Android**：底图回到 2560×1440，APK 从 97.5 MB 降到 31.9 MB；单季纹理；触摸拖动不再带动页面手势。
- **Web / 离线**：内嵌底图改为 4K JPEG q90（`pond-bed.js` 60.6 MB → 9.9 MB），在线部署仍使用无损 PNG；三首原始 wav 不再重复随包，只保留 `SOURCES.md` 署名。
